1

Claude Code を入れる

これが本体。ここだけで一応使えるようになる

先に契約が要る。Claude Code は Pro / Max / Team / Enterprise のいずれかが必要で、 無料のClaude.aiプランでは使えない。個人なら Pro（$20/月）から。

① インストール（どちらか片方）

公式インストーラ。自動で更新される（おすすめ）

curl -fsSL https://claude.ai/install.sh | bash

Homebrew を使っているなら

brew install --cask claude-code
Homebrew版は自動更新されない。ときどき brew upgrade claude-code を打つ必要がある。こだわりが無ければ上の公式インストーラでよい

① インストール（どちらか片方）

PowerShell を開いて（管理者権限は不要）

irm https://claude.ai/install.ps1 | iex

winget を使うなら

winget install Anthropic.ClaudeCode
プロンプトが PS C:\ で始まっていれば PowerShell、C:\ だけなら CMD。 CMD で上のコマンドを打つと 'irm' is not recognized と出る。
WSL は必須ではない。Windows にそのまま入れて動く。ただし Git for Windows を入れておくと、AIが Bash を使えるようになって挙動が揃う（入れないと PowerShell で動く）。

② 入ったか確かめる

claude --version
claude doctor

2.1.211 (Claude Code) のようにバージョンが出れば成功。claude doctor は設定の健康診断で、問題があれば直し方まで出る

③ ログインする

claude

実行するとブラウザが開くので、契約しているアカウントで承認する。これで使える状態になる

2

Codex を入れる

OpenAI版のターミナルAI。ルールは Claude Code と同じものを読ませる

① インストール（どれか1つ）

curl -fsSL https://chatgpt.com/codex/install.sh | sh

Homebrew なら

brew install --cask codex

npm なら

npm install -g @openai/codex

① インストール（どちらか片方）

PowerShell で

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

npm なら

npm install -g @openai/codex

② 起動してログイン

codex

初回に Sign in with ChatGPT を選ぶ。ChatGPT Plus 以上のアカウントが要る

③ 同じルールを読ませる

ルールを2つ持つと必ず片方が古くなる。正本は1つにして、Codexからは参照させる

AGENTS.md               ← Codex が読む入口。中身は「.claude/CLAUDE.md を読め」の1枚
.claude/CLAUDE.md       ← ルールの正本。直すときは必ずこっち
.codex/hooks.json       ← 会話の自動保存・ドメイン判定・書き込みガード

この3つは下のファイル一覧から落とせる。リポジトリの中で codex を起動すれば、AGENTS.md を読んでから作業に入る

Codex では使えないもの。担当別のAI（.claude/agents/）とスキル（.claude/skills/）は Claude Code の機能なので Codex からは呼べない。ルール（.claude/rules/）は普通に効く

周辺アプリ — 何がどの役割か

おすすめは出すが、入れるかどうかは自分で決める。チェックを外したものは以降の手順から消える

この4つの役割分担だけ覚えれば迷わない。
考える・書く＝Obsidian ／ 管理する＝Notion ／ 資料に聞く＝NotebookLM ／ 置く＝Drive
同じ内容を2ヶ所に書かないこと。片方が必ず腐る
4

キットを入れる

AIへの指示・ルール・スクリプト一式を自分のPCに置く

① 置き場所を作って、キットを展開する

下のファイル一覧から落としたものを、この構造で置く

~/あなたの作業フォルダ/
├── .claude/
│   ├── CLAUDE.md          ← AIへの指示の最上位
│   ├── rules/             ← 決めごと
│   ├── agents/            ← 担当別のAI
│   └── skills/            ← 定型作業
├── 01_intern/             ← 仕事
├── 02_school/             ← 学校
└── scripts/               ← 自動化

② セットアップを走らせる

bash setup.sh

名前・Vaultの場所・使うドメインを聞かれるので答える

bash setup.sh
Windows では Git Bash か WSL の中で走らせる。PowerShell では動かない。 Git for Windows を入れていれば「Git Bash」から実行できる

③ 動くか確かめる

claude

作業フォルダで起動して「今日やることを教えて」と話しかける。CLAUDE.md を読んだ答えが返れば配線できている

Windows で動かないもの。毎朝の自動同期は macOS の LaunchAgent で組んである。 Windows で同じことをするならタスクスケジューラに読み替えるか、WSL の cron を使う。 手で走らせる分にはスクリプトはそのまま動く
